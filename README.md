# WINE-Citra
## What is Citra?
Citra is a WINE shell made in python with one soul purpose; making WINE usage easier without needing to open the terminal each and every second. The shell is currently in beta and is early to development but as of now it works at all.
## What does Citra work on?
Citra only works on Linux mint, and maybe any Debian instance, I'm not sure, I'm on Linux mint.
