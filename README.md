# WINE-Citra
## What is Citra?
Citra is a WINE runtime shell made in python made for making WINE usage easier, it's as simple as just doubling clicking a windows application as you would on an actual windows device. This thing comes with an additional graphical interface desktop application for settings and customization. Citra also comes with a crash handeler to try and let the user know what happened by using the logs to its adavntage
